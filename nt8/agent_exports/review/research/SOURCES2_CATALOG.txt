HOW THE SWEEP WAS DONE
 - 4 web scouts (WebSearch/WebFetch only): academic (33 candidates), practitioner sites/books (46), open code + verified records (38),
   YouTube discovery (54 + 10 channels). The shared 200-search budget ran out for all four; quantifiedstrategies.com, SSRN and several
   PDFs were blocked or unreadable - listed below where it mattered.
 - YouTube: 75 queries through YouTube's own search API -> 1,101 videos ranked; 314 transcripts fetched (iOS player API - nothing
   played); 157 kept by a rule-density screen and read in full by 10 extractor agents. Only rules are kept, no transcript text.
