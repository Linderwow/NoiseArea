WHAT CHANGES
 G1. Desync guard compares size, not just direction. Now: Math.Sign(acctQty) != cur. New: acctQty != cur x Position.Quantity.
     Why: an extra same-direction position (manual add, copied trade, duplicate instance) went unnoticed until after the exit
     and was then left open.
 G2. A desync that persists is ended by stopping the strategy, without flattening. Now: a desync blocks only the strategy's
     own orders; NinjaTrader's own exit-on-session-close and the StopCancelClose error handling still act on the strategy's
     stale bookkeeping, so after an external flatten they can OPEN an opposite position (e.g. at 16:59:30) that is held
     overnight. New: on the second consecutive real-time bar that is still desynced (one 5-minute bar of grace for a fill in
     progress, as today), the strategy writes the heartbeat with state "desync" and a note naming both positions, logs the
     event, raises the alert, and calls SetState(State.Terminated). A terminated strategy sends nothing further (no
     session-close exit); the account position is left as it is for a human to reconcile. The Terminated handler keeps the
     "desync" state in the heartbeat instead of overwriting it with "terminated".
 G3. Daily loss stop survives a restart. (a) A saved halt is restored only when the stop is on (MaxDailyLoss > 0); today a
     halt saved under an earlier setting is restored even with the stop off and blocks the rest of the session. (b) The
     halt for the current session is read when the data loads and applied to that session's historical replay too, so the
     start-up account synchronisation ("Immediately submit, synchronize account") cannot re-enter the position the halt
     closed. (c) The day state is also saved after every real-time position change and at termination, not only at the next
     bar close, so a shutdown between bars cannot lose the session's realized loss.
 G4. An append-only event log NoiseArea_events_<inst>_<acct>.txt in agent_exports (ET timestamp | event | detail) for desync
     rise/clear, desync stop, halt, halt restored, history alert, live start and termination - these were visible only in
     NinjaTrader's unsaved Output window (double verification: intermediate states left no record).
 Header comment updated to describe G1-G4.
